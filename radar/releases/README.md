# Uscite

Ogni uscita è una cartella `YYYY-MM-<ambito>/` con:

- `release.json` — metadati e scelte con id stabili, validato da `radar/schema/release.schema.json`
- eventuali CSV di pool e di errata, come per ottobre 2026

Le uscite pubbliche possono generare (in un passo successivo) le pagine HTML. Le uscite a pagamento restano file di dati finché non si decide di pubblicarle: non inventare mesi futuri e non mettere HTML pubblico per quelle private.

L’Uscita 01 è `2026-10-girone-d`.
